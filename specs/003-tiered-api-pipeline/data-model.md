## Entities

### Script Type (`SCRIPT` enum)

| Value | Meaning | DeepL called? | Claude schema |
|-------|---------|---------------|---------------|
| `kor` | Korean (Hangul dominant) | Yes, if key set | particles + endings; romanization omitted (local) |
| `jpn` | Japanese (Kana present) | Yes, if key set | romanization required |
| `cmn` | Chinese (CJK dominant, no Kana) | Yes, if key set | romanization required |
| `lat` | Latin script dominant | **No** | standard schema |
| `und` | Undetermined (no script chars) | **No** | standard schema |

Source: `lib/lang-detect.js` — exported as `SCRIPT` object.

### DeepL API Key

| Attribute | Value |
|-----------|-------|
| Storage key | `deeplKey` in `chrome.storage.local` |
| Memory cache | `cachedDeeplKey` (module-scope `let`, initialized `null`) |
| Cache invalidation | Set to new value on save; set to `null` when saved blank |
| Sent to | `api-free.deepl.com` as `Authorization: DeepL-Auth-Key <value>` header |
| Never sent to | Anthropic API, any other endpoint, console output |
| Type | `string | null` |

### Conditional Tool Schema Shape

The `linguistic_analysis` tool's `input_schema` varies per call. The base shape is:

```
{
  tokens: Token[]        // always required
  translation?: string   // required when preTranslation is null; omitted otherwise
}
```

**Token shape** (varies by lang):

```
{
  word:          string   // always required
  lemma:         string   // always required
  pos:           string   // always required (allowlisted)
  meaning:       string   // always required
  romanization?: string   // required for JPN and CMN; absent for KOR (local) and LAT
  particles?:    Particle[] // KOR only, optional
  endings?:      Ending[]   // KOR only, optional
}
```

**Particle shape** (KOR only):

```
{
  form:    string   // e.g. "는"
  type:    string   // allowlisted: topic | subject | object | sentence-end | other-particle
  meaning: string
}
```

**Ending shape** (KOR only):

```
{
  form:    string   // e.g. "고"
  type:    string   // allowlisted: connective | attributive | nominal | concessive | sentence-final | other-ending
  meaning: string
}
```

### Pre-Translation Merge Rule

After Claude responds and `preTranslation` is set:

```
if (preTranslation && !result.translation) {
  result.translation = preTranslation;
}
```

`validateResponse` then checks `result.translation` — it will always be present because:
- Either Claude provided it (schema included it, i.e., `preTranslation` was null), or
- It was patched in from DeepL (above merge)

### Storage Shape (chrome.storage.local)

```json
{
  "apiKey":   "sk-ant-...",
  "deeplKey": "....:fx"
}
```

`deeplKey` is optional — absent from storage when no key is saved. Both keys read in a single `chrome.storage.local.get(['apiKey', 'deeplKey'])` call.
